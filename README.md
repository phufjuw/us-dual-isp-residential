## 美国双ISP住宅IP到底是什么，怎么自己验证

先把概念拆成能查的东西，不然“双 ISP”很容易被讲成玄学。

第一层看 ASN。每个 IP 都归属某个自治系统，机房 IP 的 ASN 通常挂在云服务商或数据中心运营商名下，平台风控一查就知道这地址不是家用宽带。住宅 IP 的 ASN 注册在真实运营商名下，LisaHost 这条美国线的 IP 落在 **AS2914（NTT America）** 段，近期还上了 192 号段的 NTT Americas 资源。你拿到机器后，用 ipinfo 或 bgp.he.net 查一下 ASN 和组织名，几秒钟就能确认这一层。

第二层看 IP 数据库标记。同一个 IP，在不同数据库里的 usage type 可能写着 ISP、residential 或者 hosting。机房段基本都会被标成 hosting 或 business，家宽段则偏向 ISP/residential。多查两三个库，取多数结果，比只看一家可靠。

第三层看历史滥用记录。IP 是循环资源，上一任租户拿它干过什么，会留在黑名单里。这项最容易被忽略，也最容易解释“为什么配置一样，我的号还是被限”。LisaHost 的政策是 IP 在黑名单内、开通 24 小时内可免费更换，超时更换要收费，所以机器到手第一件事就是查一遍再开始用。

至于“双 ISP”这个词本身，公开资料里存在两种说法：一种指 IP 的 ASN 在两个运营商维度上做了归属处理，纯净度高于普通 ISP IP；另一种指同一个 IP 被两家 ISP 登记为家庭宽带用户地址。两种说法都不是行业强制标准，落到可验证的层面，还是回到 ASN 归属加数据库住宅标记这两件事上。你在选购时不必纠结字面定义，直接查这两项就行。

机房 IP 被降权的逻辑也很朴素：平台先看 ASN 和组织归属，再看数据库里的类型标记，两关都指向数据中心，账号就先背一个默认的不信任分。住宅 IP 不是给你免死金牌，只是让你从起跑线后退的那一步里走出来。
